# DNA methylation analysis

Code for offspring blood and liver, comparing FLI 2 h with unexposed controls separately in each tissue. Positive effects indicate higher methylation in the imaging group.

## Workflow

Per-sample CpG counts → coverage assessment and global methylation → candidate regions → regional testing → annotation and visualization.

Scripts are pending upload by the study authors. Retain the actual regional and DSS analyses with clearly distinguished purposes, including the primary and sensitivity analyses. Group-pooled tracks are for display; statistical analysis retains separate samples.

This reanalysis starts from processed CpG counts. Upstream FASTQ processing is included only if the actual scripts become available. Required software, execution order and data links will be documented with the uploaded scripts.
